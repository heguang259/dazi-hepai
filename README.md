# 搭子合拍

出行前 30 秒测出旅行默契分，自动生成「旅行公约」，把丑话说在前头。

**在线体验**：https://dazi-hepai.app.workbuddy.host/

## 这是什么

出行前，让同行的每个人各答 8 道题（作息、节奏、预算、口味、拍照、计划性、购物、景点偏好），勾选自己的「雷点」，一键算出全队旅行默契分与两两合拍度，并自动生成一份可以发到群里的「旅行公约」。

78% 的年轻人找过旅游搭子，其中 41% 第一天就想散伙——多数不是因为目的地，而是节奏、预算、作息对不上。这个页面就是用来在出发前把这几个问题摆到台面上的。

## 怎么用

1. 打开链接
2. 填同行搭子名字（2–6 人）
3. 每人轮流答 8 道题并勾选「雷点」
4. 一键生成合拍度报告和旅行公约
5. 点「复制公约」发到群里

## 技术说明

纯静态单文件页面（`index.html`），零依赖、零外部接口，所有计算都在浏览器本地完成，数据只存访问者自己的浏览器，不上传服务器。
